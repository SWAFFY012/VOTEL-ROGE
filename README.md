# VOTEL-ROGE

Интерактивная промо-страница на React, TypeScript, Vite, Tailwind CSS, GSAP ScrollTrigger и Three.js. Backend отсутствует.

## Запуск

```bash
npm install
npm run dev -- --port 5173
```

Локальный адрес: http://127.0.0.1:5173/

Проверки: `npm run check` и `npm run build`.

## Сценарий

- Загрузчик считает до 100%, раскрывая видео через центральную рамку.
- Hero первый раз показывает видео целиком: от серой композиции до полного цвета. Следующие циклы начинаются с 4,9 секунды — уже с цветных цветов — и продолжаются до появления портрета. Видео идёт без звука на скорости 1× и не зависит от прокрутки.
- `VOTEL-ROGE` и курсивное `ЛУДЖИ` по прокрутке уменьшаются и уходят вверх.
- На белом фоне гитара целиком выходит из нижней кромки, занимает почти весь экран и делает полный объёмный оборот. Крупная типографика проходит поверх силуэта.
- После оборота гитара уменьшается и фиксируется под `ЛУДЖИ`.
- Следующая сцена появляется из маленького прямоугольного видеокадра и расширяется почти на весь экран.
- Музыкальные площадки разнесены на шесть отдельных максимально прозрачных glass-плашек; справа остаётся отдельная плашка знакомства с проектом.
- На мобильных устройствах композиция перестраивается без горизонтальной прокрутки. Для `prefers-reduced-motion` сразу показывается спокойное конечное состояние.

## Структура

- `src/App.tsx` — основной сценарий и GSAP-хореография.
- `src/components/LoadingIntro.tsx` — загрузчик и раскрытие hero.
- `src/components/GuitarScene.tsx` — Three.js-гитара и её поворот.
- `src/components/ui/blur-fade.tsx` — blur reveal для финальных плашек на основе 21st.dev/Magic UI.
- `src/style.css` — адаптивная композиция, рамки и стеклянные панели.
- `public/intro.mp4` — фоновое видео.
- `public/guitar-*.png` — приложенные ракурсы гитары.

Визуальная хореография сделана по референсу Vero Studio, но реализована в коде проекта. Старый прогиб фоновой фотографии и привязка кадров видео к колесу удалены.
